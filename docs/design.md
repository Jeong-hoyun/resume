# UI 방향

프로젝트 스킬 `.agents/skills/frontend-design/SKILL.md`를 적용합니다.

## 토큰

- Paper `#FFFFFF`: 문서 본문
- Canvas `#F3F6FA`: 탐색 영역과 보조 시각화
- Ink `#20314C`: 본문·주요 탐색
- Muted `#5C6B7E`: 날짜·설명
- Blue `#345CCE`: 현재 선택·링크·포커스
- Line `#DFE5EE`: 내용 구분

IBM Plex Sans KR를 한국어 본문에, Noto Sans JP를 일본어 본문에 사용합니다. 네트워크 폰트 로딩 실패 시 시스템 sans-serif를 사용합니다. 본문은 긴 문장을 읽기 쉽게 제한된 폭과 충분한 줄 간격으로 표시합니다.

## 레이아웃

```
문서 탐색       현재 문서 / 이름
이름           소개 문장          재생 화면 도해
이력서         경력 목록
직무경력서     주요 프로젝트
포트폴리오     기술 / 학력
언어 / 인쇄    관련 링크
```

PC에서는 문서 탐색을 고정하고, 모바일에서는 상단 탭으로 전환합니다. 내용은 왼쪽 정렬합니다. A4 인쇄에서는 탐색·장식·필터를 제외하고 본문을 연속 배치합니다.

## 검토 후 반영한 선택

범용 포트폴리오처럼 큰 성과 숫자만 소개에 배치하지 않고, 실제 경험인 플레이어의 프레임·로딩·포커스 흐름을 CSS 도해로 표현합니다. 모든 섹션에 영문 대문자 라벨이나 번호를 붙이지 않습니다. 성능 지표는 상세 사례에서만 측정 조건·전후 표와 함께 제시합니다. 제품 도해는 실제 서비스의 스크린샷이 아니라 설명용 이미지입니다.
