# 한국어·일본어 문구 검토

최초 검토 범위는 Google Sheets의 `ko!A2:D137`, `jp!A2:F137`, 사이트에서 사용하는 번역 스냅샷, 컴포넌트에 직접 작성된 문구입니다. 최초 검토에서 총 136개 키의 한국어·일본어 272개 문장을 확인했습니다. 아래 원문과 제안은 당시 기록입니다.

최초 검토 당시 시트와 사이트의 문장은 일치했습니다. 이중 공백, 앞뒤 불필요한 공백, NBSP·제로폭 공백·BOM은 발견되지 않았습니다. 문장 중간의 의도된 줄바꿈은 오류로 보지 않았습니다. PDF의 글자 잘림·줄바꿈·폰트 문제는 이 텍스트 검토와 별도로 실제 출력물을 확인해야 합니다.

## 반영 완료

사용자 요청에 따라 우선 수정 10개와 문체·띄어쓰기 제안 20개를 전체 반영했습니다. 중복되는 항목을 묶어 기존 문장 27개 키를 점검·수정하고, 도해용 문장 1개 키를 추가했습니다. 시트·번역 기본값·생성 스냅샷을 함께 갱신했습니다.

- 총 번역 키는 165개이며, 점검한 일본어 문장은 `reviewed`로 표시했습니다.
- 한국어 원문 해시와 일본어 검수 대상 해시를 같은 값으로 갱신했습니다.
- SDK의 최신 FIFO 처리 이력과 AI 리뷰의 댓글 폴백 설명은 보존했습니다. 쿠키 표현은 이미 수정되어 있어 기존 표현을 유지했습니다.
- 회사명·이름·학과명·자격증명, 확정한 날짜·성과 수치는 유지했습니다. `履歴書` 메뉴도 유지했습니다.
- 일부 제안이 문장 일부만 제시한 경우 전체 문맥에 맞게 연결했습니다. 예를 들어 대시보드 제목의 `확인하도록`은 `확인합니다`로 마무리했습니다.
- 아래의 원문·제안은 변경 이유를 확인할 수 있도록 남겨둡니다. 일본어 수정안은 자동 번역 결과가 아닌 문맥을 고려한 교정입니다.

키: `performance.note`

- 한국어 원문: 내부 측정 · Galaxy S20 Ultra · 유형별 동일 시나리오 3회 중앙값. 감소율은 4개 방송 유형별 개선율의 단순 평균을 반올림했습니다.
- 한국어 제안: **내부 측정 결과입니다. Galaxy S20 Ultra에서 방송 유형별로 동일한 시나리오를 3회 측정한 뒤 중앙값을 사용했습니다. 감소율은 4개 방송 유형의 개별 개선율을 단순 평균한 뒤 정수로 반올림한 값입니다.**
- 일본어 제안: **社内での計測結果です。Galaxy S20 Ultraを使用し、配信タイプごとに同じシナリオを3回計測した中央値を採用しました。短縮率・削減率は、4タイプの改善率を単純平均し、整数に四捨五入した値です。**

“3회 중앙값”에는 측정의 대상이 생략되어 있습니다. 일본어에서도 시간과 데이터량을 모두 `短縮率`로 부르기보다 나누는 편이 정확합니다.

### 3. 지원자 소개에 포함된 사이트 구현 설명

키: `career.intro`

데이터 공유 구조는 README에 적합한 설명입니다. 채용 문서 본문에서는 담당 업무를 이해하는 데 도움이 되는 문장으로 대체하는 것이 좋습니다.

### 4. 키보드가 이동한다는 뜻으로 읽히는 표현

“상품 진입”은 상품 정보 화면인지 구매 과정인지 불명확합니다. `クリップ探索`도 일반적인 채용 문장에서는 `クリップの切り替え`나 `動画の閲覧`이 자연스럽습니다.

## 문구 외에 확인할 점

- 일본어 이력서 메뉴가 `履歴書`이지만 현재 화면은 일반적인 일본 제출용 이력서 양식보다는 프로필·경력 요약 페이지에 가깝습니다. 웹 페이지 이름으로는 사용할 수 있으나, 제출처가 정해진 양식을 요구하면 별도 양식이 필요합니다. 현재 메뉴를 반드시 바꿔야 한다는 의미는 아닙니다.
- `ProjectVisual.astro`의 포커스 안내 문구를 `visual.accessibility.focus` 키로 옮겼습니다. 수정한 한일 문장은 이제 시트에서 관리합니다.
- 영문 기술명 앞뒤에 일본어식으로 공백을 넣지 않은 `Reactの`, `Web SDKを` 등은 정상적인 표기입니다. 한국어 기준으로 일괄 공백을 삽입하지 않는 것이 좋습니다.
- 이름·회사명·학과명·자격증 번역은 고유명사이므로 표현이 낯설다는 이유만으로 변경하지 않습니다. 특히 `韓国海洋大学校`, `鄭 皓允`은 이번 교정 대상에서 제외했습니다.
- 사용자 확정값인 평균 시청 시간 약 10%, 경력·졸업·프로젝트 기간은 그대로 유지합니다.

## 반영할 때의 순서

1. 시트의 해당 key를 찾아 `ko.text`, `jp.reviewed_ja`를 수정합니다.
2. 한국어 변경분의 `source_hash`를 갱신하고 일본어 검수본의 `reviewed_source_hash`도 같은 값으로 맞춥니다. `status`는 검수 후 `reviewed`로 지정합니다.
3. 검증 로직으로 시트를 다시 읽어 공개 번역 스냅샷을 생성합니다. 자동 생성 JSON만 직접 고치지 않습니다.
4. 기본 문장 파일도 수정하기로 한 경우 시트와 같은 표현으로 맞춥니다. 기본 문장 파일 변경만으로는 현재 사이트 문구가 바뀌지 않습니다.
5. `npm run check`, `npm run build` 후 한국어·일본어 화면과 인쇄 결과를 확인합니다.
